# The Squad v81 — Neighborhood Realism

## City-only development
- Added distinct architectural identities for the financial core, heritage quarter, garden quarter, innovation blocks and residential district.
- Added layered street-level podiums, framed glass entrances, canopies, vertical facade fins, mid-height bands and roof crowns to procedural skyline buildings.
- Added four illuminated neighborhood gateway markers to make city districts easier to recognize.
- Details use the existing batched mesh system; no gameplay collision or vehicle geometry was changed.

## Preserved
- Chat modules and chat behavior.
- Vehicle geometry, catalog, materials, reflections and GLB models.
- Firebase configuration, Firestore/Storage rules and economy backend.
