# The Squad — Visual pass v55

This is a follow-up to v54. All original project files remain included; only existing rendering files are edited and this changelog is added.

- Increased car body bevel quality for smoother silhouette highlights.
- Added subtle wheel-arch lips and side-window B-pillars to the existing procedural car meshes.
- Reduced minimap redraw frequency from ~7 times/second to ~4.5 times/second to save CPU on older devices.
- Preserved the existing car controls, catalog IDs, Firebase logic, economy, and project layout.

This still uses procedural car geometry. It is not a substitute for licensed production GLB/GLTF vehicle models. The site has not been deployed by this local archive update.
