# The Squad v126 — Handcrafted Luxury Vehicle Meshes

## Built in this release
- Added dedicated procedural silhouette profiles for Rolls-Royce Phantom, Rolls-Royce Cullinan, Rolls-Royce Ghost and Cadillac Escalade-V.
- Added custom luxury front fascias, deep waterfall-style grilles, vertical lamp signatures, chrome coachlines, door shut-lines, running boards, roof rails and model-specific rear lighting.
- Added a distinctive upright Cullinan/ Escalade SUV roof and rear body profile, and a long formal Phantom sedan profile.
- Added small rear executive-cabin detailing for the Rolls-Royce Phantom family.
- Updated showroom display to use the custom Phantom profile.
- Updated the car gallery to identify cars with dedicated procedural geometry.
- Kept existing city buildings, roads, parks, palace, villas, collision map, vehicle physics, ownership and multiplayer vehicle sync unchanged.

## Accuracy and licensing note
These are original procedural Three.js game meshes built from code. They are recognisable, model-specific game interpretations, not OEM CAD, manufacturer-approved models, official badges, or licensed 1:1 replicas. No third-party model files or manufacturer logos were copied or bundled.
