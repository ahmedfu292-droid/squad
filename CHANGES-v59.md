# The Squad v59 — precision luxury architecture pass

- Built on the v58 visual-regression rollback, preserving the existing app and multiplayer/vehicle logic.
- Added a focused architectural detailing pass to estate properties: layered glazing, metallic frames, standing-seam roof ribs, stone courses, driveway joints, and layered planting.
- Kept additions low-poly and limited to the estate zone to avoid adding large costs to the whole city.
- This is custom procedural Three.js geometry, NOT externally sourced photorealistic vehicle/building GLB assets. No imported real-world model files were available in the workspace, so this release does not claim those assets are integrated.
- Validation: JavaScript syntax checks and archive integrity checks are required before delivery. Browser rendering can still depend on external Three.js CDN availability.
