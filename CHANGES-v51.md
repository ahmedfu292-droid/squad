# The Squad v51 — Personal Bodyguards & Luxury Convoy

- Added a dedicated in-game panel opened from the new 🛡️ موكبي button.
- Players can hire a personal bodyguard using the existing server-authoritative `hireStaff` economy action, requiring ownership of an estate and charging the existing 2,500 guard fee.
- Added a toggle to have hired bodyguard avatars follow the local player.
- Added a visual luxury convoy (Bugatti, Rolls-Royce, Range Rover archetypes) that follows the player in the current game session, with an on/off toggle.
- Existing files/features are retained; no external model assets are bundled. Convoy and bodyguard following are session-local presentation features, not synchronized multiplayer entities or persistent vehicle ownership.
