# The Squad v127 — Expanded Luxury Fleet

## Added model-specific procedural profiles
- Bugatti Chiron and Bugatti Tourbillon
- McLaren 750S and McLaren P1
- Mercedes-Benz S-Class and Mercedes-AMG GT Black Series

## Geometry
- Separate body proportions and side silhouettes for each model family.
- Dedicated front fascia details: grille/intake, lighting signature, trim and lower aero.
- Dedicated rear lighting / aero details where applicable.
- Uses the existing vehicle catalog IDs and preserves current city, buildings, roads, palace, ownership, physics and multiplayer code.

## Accuracy and licensing
These are original procedural game meshes inspired by the named vehicle classes. They are not OEM CAD, manufacturer-approved, or licensed 1:1 replicas. No manufacturer logos or third-party model files are bundled.

## Validation
Automated syntax and targeted profile tests are included. Browser visual QA, WebGL device testing and real multiplayer driving tests remain necessary.
