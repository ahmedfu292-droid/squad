# v154 Cloud Functions

This is a review copy of the complete current The Squad Functions entry point with three owner-only additions: `searchAdminAccounts`, `getAdminAccountActivity`, and `getAdminReports`.

This directory is the separate deployment source, with `backend/firebase.json` pointing to it. The source baseline under `source/The-Squad-v137/` remains unchanged.

Deploy this source through Firebase CLI from the `backend/` directory, using the project's intended ID. Do not upload this folder as static web assets.
