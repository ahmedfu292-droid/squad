THE SQUAD v117 — LUXURY FLEET & CITY BUILD

This package continues directly from The-Squad-v116-Servers-Final.zip.

UPLOAD
1. Extract the ZIP.
2. Open the folder The-Squad-v97-Stage4-Social-Chat.
3. Upload the CONTENTS of that folder to the static hosting root (keep all subfolders).
4. Do not upload the outer wrapper folder as a nested website directory.
5. Keep the existing Firebase configuration and rules as they are; this package does not deploy rules.

WHAT CHANGED
- Four dedicated 2026 SUV models: Cadillac Escalade-V, Range Rover SV, BMW X6 M Competition,
  and Mercedes-AMG G 63.
