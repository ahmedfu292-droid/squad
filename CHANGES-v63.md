# The Squad v63 — visual design reference package

This build packages the current v62 project plus the generated fleet/city concept poster under `assets/design/` as a visual direction reference.

Included from v62:
- 120 named entries in the in-game vehicle catalog.
- Four local generic GLB archetypes (sedan, sport, supercar, SUV).
- Transparent building/estate glass material changes.
- Procedural fallback for vehicles if GLB loading fails.

Important truth-in-labeling notes:
- The poster is a concept/reference image; it is not a screenshot of the live game and is not itself a set of 3D models.
- The four GLB files are generic category models, not 120 manufacturer-accurate models.
- Browser visual, drive, and multiplayer testing has not been completed in this environment. Do not replace the production deployment without testing.
