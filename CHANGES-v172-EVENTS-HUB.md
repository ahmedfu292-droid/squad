# v172 — Events Hub

## Added
- Personal event creation with title, category, date/time, and description.
- Event list filters: all, upcoming, attending, and past.
- Personal RSVP toggle, mark-as-done, and delete actions.
- Account-scoped local persistence and explicit privacy messaging.
- Responsive dark/gold interface and launcher in the existing Squad hub/action area.

## Boundaries
- This is a personal local planner, not yet a shared live events service.
- No invitations, public attendee counts, push notifications, or Firebase writes are claimed.
- No existing files or Firebase rules were removed or changed.
